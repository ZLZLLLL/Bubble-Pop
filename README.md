# Bubble-Pop · 云间小铺

参考古风合成茶铺玩法制作的可玩网页原型。运行时无外部依赖，使用用户提供的素材，经裁切、透明底处理后打包为 WebP 图集；少量未提供的图标继续使用内置 SVG。

部署版：Node.js 24，先 `npm run build`，运行 `npm start` 后在游戏内登录，访问 http://localhost:5188 。需要服务器运行，不再支持双击 HTML 离线游戏。详见 DEPLOY.md。

验证游戏逻辑：`npm test`。

- 拖拽相同物品合成，也支持依次点击两件物品与键盘 Tab / Enter。
- 稻米链：稻谷 → 香米 → 饭团 → 便当 → 盛宴。
- 茶点链：茶叶 → 清茶 → 紫砂壶 → 菊花清饮 → 桃花酥 → 花朝庆糕。
- 稻米篓与茶点篮独立出物，每次消耗 1 体力；棋盘与底部均有对应入口。
- 集齐订单后，将其中一件所需物品拖至顾客托盘，一次交付整单；点击托盘不会交付。每 3 单升一级，最高 5 级。
- 选中仅显示细边框，不缩放、不高亮同类。键盘用户可选中物品，再 Tab 到顾客并按 Enter 交付。
- 旧存档保留已有物品，优先在空格或未开放格补入茶点篮；棋盘已完全占满时仍可使用底部生成入口，清出位置后重载即可补入。
- 相邻竹帘每格花费 15 铜钱解锁。
- 游戏内登录、退出；点击体力旁的 + 或「兑换体力」输入兑换码领取。每码每账号限领一次。
- 可选合成音效、SQLite 服务器存档及本地副本。

这是单账号轻量网页游戏，初始账号为 lulu，密码采用用户指定的八位初始值；未开放注册和支付。旧存档会保留，密码哈希、登录会话与兑换记录存入 SQLite。

构建与加载方案见 `assets/README.md`。仓库包含运行所需的压缩图集；原始素材、独立 PNG 和本地素材预览页未上传，重新抠图需自行提供原素材。
